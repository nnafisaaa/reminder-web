NAMIRA TUGAS1NAJA — CLEAN PASTEL EDITION

Cara pakai:
1. Buka index.html di browser.
2. Tambah order, nama atau 4 digit HP, jenis, topik, deadline, detail, harga, dan pembayaran.
3. Tentukan beberapa pengingat H- menit/jam/hari per order.
4. Bagikan invoice melalui WhatsApp, fitur Bagikan, atau Salin invoice.
5. Gunakan tombol Bayar untuk mencatat cicilan dan pelunasan.
6. Untuk pengingat saat browser tertutup, unduh Kalender HP (.ics), impor ke aplikasi kalender, dan pastikan notifikasinya aktif.
7. Backup JSON secara berkala; data lokal tidak otomatis sinkron ke perangkat lain.

Keterbatasan: notifikasi website aktif saat halaman dibuka dan dengan izin browser di HTTPS; bukan push notification yang terus bekerja saat tab ditutup.

Website ini menggunakan penyimpanan lokal dan tidak memerlukan backend.
